## Problems Solved

### 1. Diagonal Difference
- Language: C++14
- Topic: 2D Arrays / Matrices
- Time Complexity: O(N)
- Space Complexity: O(1)

### 2. Dynamic Array
- Language: Python 3
- Topic: Arrays, Nested Lists, Bitwise XOR
- Time Complexity: O(N + Q)
- Space Complexity: O(N)

### 3. Time Conversion
- Language: Python 3
- Topic: Strings and Logic
- Time Complexity: O(1)
- Space Complexity: O(1)

### 4. Compare the Triplets
- Language: Python 3
- Topic: Comparison and Score Tracking
- Time Complexity: O(1)
- Space Complexity: O(1)

### 5. Sparse Arrays
- Language: Python 3
- Topic: Hash Maps / Frequency Mapping
- Time Complexity: O(N + Q)
- Space Complexity: O(N)
